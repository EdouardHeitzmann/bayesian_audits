# bayesian_audits

Main entry point: `adversarial_profile.ipynb`.

Also included:
- `scottish_profile.ipynb` (uses local data path `data/scot-elex/6_cands/aberdeenshire_2012_ward9.csv`)
- `src/` (core Python code used by the notebooks)
- `requirements.txt` (exported from the project `.venv` using `uv`)

To run locally:
1. Create/activate a Python environment.
2. Install dependencies: `pip install -r requirements.txt`.
3. Open `adversarial_profile.ipynb`.
